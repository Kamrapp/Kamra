# Learnings

## Purpose

This folder stores small, durable notes discovered during planning, implementation, review, and debugging.

Use this folder when a lesson is likely to help future Kamra sessions.

Load only learning files relevant to the current task. These notes should speed up decisions, not become required reading for every session.

## Rules

- Keep each file focused.
- Prefer one topic per file.
- Link to plans or sessions when useful.
- Do not store full transcripts here.
- Promote repeated lessons into `.agents/coding-guidelines.md` or `.agents/planning-workflow.md`.
- Promote roadmap-changing lessons into the active roadmap or plan, not only into this folder.

## Suggested Names

- `identity-resolution.md`
- `crawler-sources.md`
- `serverless-migration.md`
- `testing-patterns.md`
- `frontend-decisions.md`
