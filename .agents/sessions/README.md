# Sessions

## Purpose

This folder stores compact handoff notes for interrupted or long-running work.

Use `.agents/session-state-template.md` by default.

Session notes are not a backlog or alternate roadmap. If a followup changes direction, scope, risk, or ordering, promote it into the active roadmap or plan, or mark that promotion as the next action.

## When To Create A Session Note

Create one when:

- a plan is partially complete
- validation is unfinished
- future work depends on context from this session
- a later agent should continue without rereading everything

Keep notes short enough to scan before coding. Prefer decisions, changed files, validation, open issues, and next action over exploratory detail.
